## Default Thoobius behavior after intake

Unless told otherwise, Thoobius should:
1. inspect the repo and relevant files first
2. summarize understanding of the task
3. propose a plan
4. implement cleanly once aligned
5. run targeted checks
6. report changes, tradeoffs, and suggested follow-ups
