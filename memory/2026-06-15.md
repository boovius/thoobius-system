- Captured CFB client-work note from the June 8, 2026 Audit <-> Def Method interview.
- Key audit workflow points:
  - Victoria manually enriches the Contribute activity report with match amounts from KIFIS/C-SMART-linked data and normalizes residential/billing addresses in Excel.
  - Address normalization includes lowercasing, trimming/cleaning, splitting house number from street name, and conditional formatting for likely residential-vs-billing mismatches.
  - Auditors want warnings, not hard errors, for incomplete names, billing/residential address mismatches, incomplete overridden addresses, ampersand/AND name edge cases, and zip verification failures/unavailable states.
  - Shared-card review is a pattern-detection workflow using last four digits, expiration date, and card type; two contributors are not automatically invalid, but clearly unrelated repeated use can be questioned and larger patterns can become nominee-contribution findings.
  - Ombase/backup PDFs are usually not needed for refunds if the refund appears correctly on the monthly merchant statement; PDFs remain useful for cross-disclosure comparison, duplicate/identity investigation, reconstructing odd history when contributions are deleted/re-added, and accessing identifiers like Stripe ID that may not be in the spreadsheet.
