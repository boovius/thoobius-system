# Woodward Source Library Schema

Use the Woodward Sources Notion database as the durable citation layer for climate-tech research.

Current Notion database:
- `Woodward Sources`
- URL: https://www.notion.so/7eec5015d0b048bcb0bd69e40ced2476

## Purpose

This database is for:
- structured source capture
- claim support trails
- later indexing / embedding / export
- future API-facing research memory

It is not for dumping every weak link gathered during browsing.

## Capture standard

Prefer storing sources that are:
- primary or near-primary
- strongest corroborating secondaries
- quantitatively useful
- standards / protocol / policy relevant
- likely to be reused later

## Fields

### Identity
- **Name**: source title
- **URL**: canonical source URL
- **Source type**: primary / secondary / company / paper / standards / etc.
- **Publisher / org**
- **Author**
- **Published date**
- **Accessed date**

### Research utility
- **Topic**
- **Company / entity**
- **Why it matters**
- **Key claim / relevance**
- **Source quality**

### BELT / modeling relevance
- **Input / output relevance**
- **Quantitative data present**
- **Extracted numbers / notes**
- **Geography**
- **Time context**

### Reuse / durability
- **Canon-worthy**
- **Research thread**
- **Deduped / canonical**

## Guidance

### Why it matters
Explain why the source was worth keeping.

### Key claim / relevance
State the main claim, question, or modeling need the source helps answer.

### Source quality
Use:
- High
- Medium
- Low

### Extracted numbers / notes
Capture useful numeric facts, ranges, units, caveats, and conditions.

### Deduped / canonical
Use when multiple URLs or writeups point back to the same underlying source and this row is the preferred record.

## Practical rule

If a source helps support BELT modeling work around:
- process input requirements
- process output assumptions
- energy input needs
- transport assumptions
- yield / efficiency
- emissions factors
- unit economics

then it is a strong candidate for capture.
