# Subagent Personas

These files are the local lightweight persona profiles for named OpenClaw subagents.

Until OpenClaw auto-loads `subagents/<label>.md` by spawn label, the coordinator should paste or reference the relevant profile in every named-persona delegation.

Required delegation pattern:

1. Tell the worker which persona they are.
2. Tell them to read their profile and memory before task work.
3. Keep the task objective separate from the persona instructions.
4. Require a completion or blockage report with checks, links, risks, and memory-worthy learnings.
5. Append those learnings to the matching `subagents/memory/<label>.md` file and update the BELT monitor/work log when applicable.
